# Solarized theme

Colours come from https://ethanschoonover.com/solarized/

`purple` is Solarized's `violet`, `pink` is `magenta`.

`gray.css` is kept by hand. Solarized's neutrals are a single ramp of warm
tinted tones shared by both modes (`base03` … `base3`), not a gray transposed
onto a background, so the built-in generator cannot reproduce them.
